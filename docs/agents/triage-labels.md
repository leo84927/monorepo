# Triage 標籤

各 skill 以五個標準 triage 角色來描述狀態。本檔案負責把這些角色對應到本 repo issue tracker 實際使用的標籤字串。

| mattpocock/skills 的角色 | 本 tracker 的標籤 | 意義                     |
| ------------------------ | ----------------- | ------------------------ |
| `needs-triage`           | `needs-triage`    | 維護者需要評估這個 issue |
| `needs-info`             | `needs-info`      | 等待回報者補充資訊       |
| `ready-for-agent`        | `ready-for-agent` | 規格完整，可交給 AFK agent |
| `ready-for-human`        | `ready-for-human` | 需要人工實作             |
| `wontfix`                | `wontfix`         | 不會處理                 |

當 skill 提到某個角色時（例如「apply the AFK-ready triage label」），改用本表對應的標籤字串。

目前左右兩欄相同，即直接沿用預設命名。若日後改用其他命名，只需修改右欄；左欄是 skill 使用的角色代號，請勿更動或翻譯。
